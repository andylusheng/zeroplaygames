# Upload guide

1. Create a new empty GitHub repository, for example:
   `zeroplaygames` or `zeroplay-games`

2. Extract the ZIP.

3. Upload the **contents inside `zeroplaygames-public/`** to the repository root.

4. In GitHub repository settings:
   - Description: `100 free browser games — play instantly, no download or sign-up.`
   - Website: `https://zeroplaygames.com/`
   - Topics: `browser-games`, `html5-games`, `web-games`, `casual-games`, `online-games`, `free-games`, `game-directory`, `game-discovery`

5. Keep this repository public-facing and documentation-first. Do not copy production secrets, Cloudflare credentials, analytics IDs, or the private runtime/source repository into it.
