ZeroPlay Games is a browser-first casual games website focused on fast, low-friction play. The production website currently includes **100 playable games**, organized into **9 categories** and **9 gameplay topic hubs**, with independent English, Simplified Chinese, Traditional Chinese, and Spanish routes.

> This is the **public project repository** for ZeroPlay Games.  
> Production source code, game runtime source, analytics configuration, and deployment secrets are intentionally not included here.

## Project principles

- Browser-first: start playing with minimal friction.
- No thin SEO synonym pages.
- Game descriptions must reflect the actual runtime behavior.
- Category pages organize inventory.
- Topic hubs organize games by gameplay mechanics.
- Game pages are both search landing pages and playable product pages.
- Cross-game discovery is a core product goal.
