# Contributing

This public repository is for project information, issue tracking, catalog feedback, and public documentation.

## Good issues

Please open an issue for:

- A game that does not load
- A broken page or link
- A mobile layout problem
- An inaccurate game description
- A control/instruction mismatch
- A translation problem
- A useful catalog or gameplay-topic correction

## Include

- Exact URL
- Browser
- Device / operating system
- Steps to reproduce
- Expected behavior
- Actual behavior
- Screenshot or recording if useful

## Production source

The production application and game runtime source are maintained privately and are not accepted through this public repository.
