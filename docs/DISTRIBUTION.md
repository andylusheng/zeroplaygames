# Distribution & Promotion

This file tracks the public channels that are appropriate for ZeroPlay Games branding and game distribution.

## Brand channels

Maintain a consistent ZeroPlay Games identity on:

- GitHub
- YouTube
- TikTok
- Instagram
- Facebook
- X

The website URL should be present in profile fields where the platform supports clickable profile links.

## Game community / distribution targets

Prioritize platforms where a real game page, developer profile, or playable HTML5 upload can exist:

1. itch.io
2. IndieDB
3. Newgrounds
4. Game Jolt
5. GameMonetize
6. CrazyGames
7. GameDistribution
8. GamePix
9. Poki

Only distribute games for which ZeroPlay Games has the necessary rights.

## Content format

For social video, a practical reusable format is:

```text
9:16 vertical
8–15 seconds
Gameplay first
Minimal text
Clear challenge / score hook
ZeroPlay Games branding
```

One gameplay clip can be adapted for YouTube Shorts, TikTok, Instagram Reels, and Facebook Reels.

## Link strategy

Do not measure progress by raw backlink count.

Prefer:

- Relevant gaming profiles
- Real developer/game pages
- Actual playable distribution
- Useful community posts
- Referral traffic
- Brand searches
- Natural citations

Avoid bulk directory spam, irrelevant profile farms, paid link packages, and mass blog-comment links.
